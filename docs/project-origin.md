# Project Origin

## What Code Janitor is

Code Janitor is an independently maintained fork and continuation of [CodeMaid](https://github.com/codecadwallader/codemaid), an open-source Visual Studio extension originally created and maintained by [Steve Cadwallader](https://github.com/codecadwallader).

Code Janitor is a separate project with its own repository, name, maintainers, roadmap and release process.

It is not presented as CodeMaid, and it is not presented as an official project of the original author.

## Why the fork was created

CodeMaid provided a valuable and widely used set of code-cleaning and code-navigation features for Visual Studio. This fork provides an independent development path as the Visual Studio platform and the .NET ecosystem evolve.

The fork was created to:

- preserve a useful open-source developer tool;
- maintain compatibility with current Visual Studio releases;
- improve the maintainability of the codebase;
- modernize the configuration experience;
- fix defects and add regression tests;
- support current development scenarios such as Razor and Blazor;
- establish a transparent, sustainable development path.

## Why the name was changed

The name Code Janitor was selected to distinguish the independently maintained project from CodeMaid.

The new name:

- makes the project's independent status clear;
- avoids implying endorsement or active maintenance by the original author;
- allows the project to establish its own roadmap and community;
- preserves the core idea of maintaining and cleaning code.

The change of name is therefore a matter of clear project identity and responsible communication, not an attempt to hide the project's origin.

## What is inherited and what is new

Code Janitor retains substantial functionality and source code derived from CodeMaid. That origin is documented openly in the repository and in the project README.

Code Janitor also contains independent work, including:

- Visual Studio 2026 compatibility; Visual Studio 2022 is no longer supported;
- grouped settings pages integrated with Visual Studio's Options dialog;
- Razor and Blazor formatting support;
- new tests and bug fixes;
- new documentation, development processes and project governance.

The Code Janitor changelog records changes made after the fork. The original CodeMaid changelog remains available in the upstream repository as historical attribution.
